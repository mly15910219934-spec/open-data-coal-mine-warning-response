# Data files

`raw/` is populated only by `python -m src.download_data` and is ignored by Git. `processed/` is reserved for derived data. `public_cases/` contains the author-supplied case coding transcribed from Table S1, the partial screening log, the unchanged source-level definitions, and an empty single-coder recheck template.

The UCI Seismic-bumps dataset has DOI 10.24432/C5W902. Do not add third-party raw files to a public release without confirming redistribution and attribution requirements.
