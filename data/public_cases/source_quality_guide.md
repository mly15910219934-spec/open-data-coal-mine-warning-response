# Source quality guide

Transcribed without changing the A-E meanings in Table S1.

## Level A

Official accident investigation report, regulator report, Royal Commission/inquiry, NIOSH/MSHA official data, state official mine-disaster record

Use: Primary evidence for Table S1.

## Level B

Official news release, government supervision notice, regulator penalty or warning-education material

Use: Usable when final report is unavailable; code conservatively.

## Level C

Peer-reviewed article, formal technical report, or company technical report

Use: Useful for engineering/model evidence, especially when official report is unavailable.

## Level D

Xinhua/CCTV/mainstream media

Use: Auxiliary only; not used as a primary source in this final table.

## Level E

Wikipedia, encyclopedia, blog, reposted news

Use: Used only as a search clue; excluded from final table.
